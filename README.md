# 🌿 AGRI-TOGO – Vitrine de la coopérative agricole

## 📖 Description

**AGRI-TOGO** est un site web vitrine conçu pour présenter une coopérative agricole togolaise. Il met en avant ses valeurs, ses produits, ses actualités et ses coordonnées afin de faciliter la mise en relation avec les producteurs locaux et les partenaires commerciaux.

> **Accès au site** : [https://agri-togo-final.vercel.app/](https://agri-togo-final.vercel.app/)

---

## ✨ Fonctionnalités principales

- **Présentation institutionnelle** : Mission, vision, promesse et histoire de la coopérative.
- **Compteur animé** : Affichage dynamique des statistiques clés (membres, régions, produits) grâce à un script JavaScript déclenché à l'apparition de la section.
- **Catalogue produits** : Liste des produits phares (Maïs, Manioc, Ananas, Farine, Gari, Jus d'ananas).
- **Actualités filtrées** : Articles classés par catégories (Foires, Formations, Récoltes).
- **Navigation responsive** : Menu adapté aux mobiles avec un système de hamburger.
- **Pied de page complet** : Coordonnées, horaires d'ouverture, liens vers les réseaux sociaux et liens utiles.

---

## 📁 Structure du projet

Le site est composé de **5 pages HTML** distinctes, reliées entre elles par un menu fixe :

| Fichier | Page | Contenu |
| :--- | :--- | :--- |
| `index.html` | **Accueil** | Bannière, mission, chiffres clés animés, dernières actualités. |
| `pages/apropos.html` | **À propos** | Histoire, domaines d'activité, valeurs, liste des producteurs membres et zones d'intervention. |
| `pages/produits.html` | **Produits** | Catalogue visuel des produits avec liens "Voir plus". |
| `pages/actualités.html` | **Actualités** | Filtrage par catégorie (Foires/Formations/Récoltes) et articles avec "Lire la suite". |
| `pages/contact.html` | **Contact** | Coordonnées directes (email, téléphone, adresse physique à Lomé). |
